This task's completion criterion is a documented finding, not necessarily a fix. Root cause: unconditional `window.__HEAD__` serialization added for the head-sync fix (D3) pays the full `snapshotPublicPayload` walk for a tiny object on every SSR response — noise on large pages, ~20-25% of total pipeline cost on very small ones.
